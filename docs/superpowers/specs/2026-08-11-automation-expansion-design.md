# 求职自动发现与批量投递扩展设计

## 目标

在现有本地工作台中加入简历导入、经历证据编辑、可配置模型/搜索 API、官方职位发现、批量官网预填与经候选人确认后的批量发送。

## 边界与交互

- 所有个人事实、筛选题回答和岗位选择都保存在本机浏览器；模型密钥不持久化。
- 简历解析先生成候选档案草稿，候选人确认后才覆盖现有档案或加入经历池。
- 岗位发现调用用户配置的 HTTP JSON 搜索接口，按官网 URL、职位标题和摘要归一化为岗位线索；具体 JD 仍通过官网页面采集复核。
- Chrome 扩展只在华为、腾讯和 PwC 中国官网，以及本地工作台页面运行。它在已登录的职位页预填已审核字段，回传逐字段审计结果。
- 批量发送仅针对已成功预填、已由候选人逐项勾选最终审核的职位，并显示总确认。登录、验证码、文件上传、未知筛选题、未找到安全提交控件或页面报错会使该职位停止，不影响队列中其他职位。

## API 适配

模型调用支持 OpenAI 兼容的 `chat/completions` 协议。搜索调用接受可配置 URL、Bearer Key 和常见 JSON 结果形态（`results`、`items`、`data.results`）；无法直接适配的厂商可由本地代理转换为该约定。

## 数据流

1. 候选人导入简历文本或 DOCX，或维护经历证据。
2. 模型把简历解析为可审核的档案草稿；确认后写入本地档案。
3. 搜索接口针对每家企业的官网域名和目标关键词返回线索，工作台评分、筛选并加入岗位池。
4. 候选人完善筛选题并选择岗位；页面通过本地扩展桥接请求扩展打开官网标签页并预填。
5. 候选人逐项审核后确认发送；扩展仅对已存在的本轮标签页触发最终提交，返回已发送或人工处理状态。

## 验证

- 单元测试覆盖 API 结果归一化、简历草稿解析、选择/审核资格与提交控件识别。
- 构建、静态检查和浏览器端桌面/移动视觉检查覆盖新增页面及批量状态。
