# 自定义官网与申请入口识别设计

## 目标

允许候选人一次导入多个招聘官网 URL 和目标职位。工作台调用已配置的大模型，对扩展读取到的页面正文与链接进行分析，找出候选申请入口；候选人审核后将其加入统一的岗位池和投递队列。

## 导入与审核流程

1. 用户粘贴或导入 CSV/TXT，每行格式为 `官网 URL, 职位目标`。
2. Chrome 扩展按本轮域名请求可选站点权限，打开页面并提取标题、可见正文和有限数量的链接。
3. 模型返回每个目标的公司名、推荐申请入口、置信度、依据、发现的登录/第三方 ATS/异常提示。
4. 原始网页摘要和模型建议以候选入口卡片展示，用户确认一个入口后才转换为岗位池记录。
5. 自定义站点岗位经过用户入口审核后标记为 `candidate-reviewed`，然后进入既有的个人资料审核、预填、逐岗位复核和总确认发送流程。

## 扩展权限与执行

- 华为、腾讯、PwC 中国保留固定官网权限。
- 任意用户导入的域名使用 Chrome `optional_host_permissions`，只在用户发起本轮检查时请求。不会加入固定 `host_permissions`。
- 后台通过 `chrome.scripting.executeScript` 在已授权的页面运行自包含页面读取、预填和最终提交动作，因此自定义招聘页无需事先硬编码内容脚本。
- 页面包含登录、验证码、必填文件、未知必填题或未识别提交控件时，返回人工处理状态。

## 模型接口

入口分析复用现有 OpenAI 兼容和自定义 JSON API 适配，要求模型严格返回每个导入 ID 对应的 JSON 记录。模型返回的 URL 必须能被解析为 HTTP(S) URL，且默认回落至候选人提供的 URL，避免把无效输出送入投递队列。

## 验证

- 单元测试覆盖批量行解析、模型 JSON 规范化、无效 URL 退回、用户确认后岗位转换和可选权限清单。
- 扩展脚本做语法检查；浏览器检查桌面与手机导入、候选入口审核页面。
