# 求职工作台 - 本地自动填写

## 简短说明

在复核后填写你已经保存的求职资料。资料和 API 配置保存在浏览器本地，不需要账号或订阅。

## 完整说明

求职工作台是一款本地优先的招聘表单填写助手，面向校园招聘、实习和社会招聘页面。

### 主要功能

- 建立和切换多份简历资料，按目标岗位保留不同版本。
- 分析当前页面可见的表单字段，展示支持度与逐项填写审计。
- 预填姓名、邮箱、电话、教育、学校、专业、毕业时间、城市、作品集链接和常用问题答案。
- 可选连接你自己的 OpenAI 兼容 API 或自定义 JSON API，协助将未知字段映射到你本地已有的答案。
- 所有自动填写都经过侧栏审计；文件上传、登录、验证码、声明题和最终提交由本人手动完成。

### 隐私与费用

- 不需要注册账号，不提供订阅或付费墙。
- 简历资料和 API Key 保存于浏览器扩展本地存储。
- 仅在你点击“用 AI 映射未知字段”后，扩展才会向你配置的 API 发送当前页面字段标签和你选择的本地资料值。
- 外部 API 服务可能自行收费，费用与本扩展无关。

### 使用方式

1. 在侧栏中保存至少一份简历资料。
2. 打开招聘网站的申请表，点击“分析页面”，并按提示授权该网站。
3. 核对审计清单后点击“填写已审核字段”。
4. 在招聘网站自行完成上传、登录、验证码、声明与最终提交。

## 权限说明

- `storage`：本地保存资料与 API 配置。
- `sidePanel`：在招聘页面显示资料、审计和填写控制。
- `tabs` 与 `scripting`：仅在用户授权的网站分析和填写可见表单字段。
- 可选网站访问权限：只在用户点击分析、填写或保存 API 时针对对应域名请求。
