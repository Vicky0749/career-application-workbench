# 求职工作台 - 本地自动填写隐私政策

生效日期：2026-08-17

## 数据存储

扩展将用户主动填写的简历资料、常用问题答案和 API 配置保存在当前浏览器的扩展本地存储中。扩展不提供账号体系、云端数据库、同步服务器、广告追踪或分析 SDK。

## 页面访问

扩展只会在用户主动授权的网站读取当前页面中可见的招聘表单控件及其标签、字段名称、placeholder、autocomplete、选项和必填状态，用于生成填写审计。扩展不会读取密码字段内容、文件内容、验证码内容或浏览历史。

## 自定义 API

只有当用户保存并主动使用自己的 AI API 时，扩展才会向该 API 发送当前页面的字段元数据，以及当前选择资料中可能用于填写的值。API Key 保存在浏览器本地。第三方 API 提供商对该请求的处理适用其自身的隐私政策。

## 不会执行的操作

扩展不会自动上传文件、处理验证码、处理登录、勾选敏感声明、点击最终提交按钮，或向本扩展的任何服务器上传个人信息。

## 联系方式

本扩展为本地优先工具。隐私问题可通过项目仓库的 Issue 区提交，不要在公开问题中包含简历、API Key 或其他敏感信息。
